        Cómo funciona el tablero
        
      
    
        
    
          
      
        1. Creá una tarjeta. Escribí qué debería explicar el documento y qué términos debe incluir. Si ya tenés un borrador, pegalo para revisarlo primero.
          2. 
      
        2. Elegí qué procesar. Iniciá un ciclo para que el planificador elija entre las pendientes, o procesá una tarjeta desde su detalle.
          3. 
      
        3. Seguí el progreso. Cuando un borrador pasa las pruebas locales, otro agente lo revisa. Si pide cambios, el redactor tiene un intento más.
          4. 
      
        4. Inspeccioná la evidencia. Encontrá el documento, los resultados de las pruebas y los recibos de selección en el historial. Si el ciclo se detuvo, podés reintentar las tarjetas bloqueadas.
          5. 
    
        
    
        Los ciclos usan tu CLI autenticado y pueden consumir turnos de tu cuenta.
